## Objective
Create the policy loader so that load_policy(path) returns a Policy from a single JSON object with exactly the four required keys, validating grace_days as an int >= 0, monthly_rate_pct and cap_pct as numbers > 0, and as_of as an ISO-8601 date, and raising LateFeeError with a one-line message for any violation including a file missing cap_pct.
